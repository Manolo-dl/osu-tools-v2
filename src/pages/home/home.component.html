Features

Downloader

Import a .txt list of beatmap set IDs and batch-download them all via BeatConnect.

→

Export Collections

Export your osu! collections to a portable format you can share or back up.

→

Export Song Folder

Copy beatmaps out of your Songs folder for backup, transfer, or archiving.

→

Getting started

  1. 1
    Confirm your osu! folder

    The bar at the top of the screen shows the detected osu! folder. If it says "not found", click Select manually and point it to your osu! installation. This only needs to be done once.

  2. 2
    Choose a tool

    Use the sidebar on the left to navigate. Each tool is independent — you can use them in any order.
